## Statistical interpretation

- An asking price is not a completed sale. Never mix them in a price distribution.
- An official land reference value does not include a home's building value. NRW **Immobilienrichtwerte** are a different product from **Bodenrichtwerte**.
- A median over reference zones is not a median over transactions. It is unweighted by area or sales volume, and changing coverage can move it even if underlying values do not change.
- NRW records may represent polygon fragments. The importer de-duplicates the same municipality, zone, type, object group, valuation date, value, build-year norm and area norm. Other reference attributes are not displayed; the original BORIS record must be checked for valuation use.
- Munich means change with the sample and property mix. The included typical living/plot sizes document part of that variation. A connected line is a visual summary of the reported observations, not a constant-quality index or proof of a specific home's change in value.
- The national Eurostat index describes broad transaction-price change and must never be transformed into invented local historical sale prices.
- Complete German address-level sale data is not publicly available as a uniform open feed. In Bavaria, the Kaufpreissammlung has access restrictions; detailed local reports/land values can require fees. The project makes the evidence boundary explicit rather than presenting estimates as records.

## Freshness and failures

An observation's period and a snapshot's retrieval date are different. Rate observations older than three calendar months are marked older in the UI. A retrieval today does not make an old observation current. Upstream publication schedules, revisions, API outages, rate limits and GitHub Actions inactivity can delay updates. Inspect Actions after a failure. Each importer validates its own source before replacing its file; a failed importer leaves that prior file intact. The workflow commits only after all selected refresh steps and tests succeed.

Manual sources require human review. Check Bavaria's report archive and the Munich report landing page at least quarterly, as well as state tax statutes when an announced change takes effect. Add new reports only after checking definitions and corrections. Do not assume a stable URL means the contents are unchanged.

- Lucide icons: ISC license. React: MIT. Other packages retain their package licenses.

Before adding another region, verify reuse rights, stable identifiers, data definitions and an implementable update path. Bavaria is the priority. Restricted or paid APIs should be optional adapters, with server-side secrets and explicit provenance; they must not silently become required by the public static app.
